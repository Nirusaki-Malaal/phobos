# Phobos design

1. Ask for the audience, goal, screen size and required content when missing.
2. Read `frontend-design` and `opendesign-integration` before generation.
3. Use `pai_ops_design_ops` only when OpenDesign is available. Preserve editable source.
4. Check contrast, keyboard focus, responsive layout and reduced motion.
5. Report the actual generated file or job result; a design brief is not a rendered mockup.
