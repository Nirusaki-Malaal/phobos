# phobos-go

Discover go.mod, Go version, package boundaries and existing task targets. Use context cancellation, bounded goroutines, explicit error wrapping and interfaces at actual seams. Keep ownership of channels clear. Prefer standard-library HTTP and existing dependencies. After implementing a batch, run gofmt, targeted tests and the race detector for concurrent code. Use pprof before claiming performance gains. Never copy a module cache into a workspace.
