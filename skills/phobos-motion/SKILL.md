# Phobos motion

Define audience, duration, aspect ratio, key message and a short storyboard first.
Keep typography, colors, timing and scene content in editable source files.
Use restrained transitions and reduced-motion variants for interactive output.

The huashu-motion workflow can be integrated from https://github.com/alchaincyf/huashu-motion
with its own license, dependencies and instructions. This Phobos pack is original guidance;
it does not bundle that renderer or claim its capabilities are installed.
Use OpenDesign for supported mockups and `phobos-stream-clipping` for local exports.
Report a storyboard as a storyboard until an actual renderer produces an artifact.
