# Phobos React Native

Read package.json, app configuration, platform folders, build profiles and the existing navigation/state patterns. Respect native permissions, background execution limits and platform-specific behavior. Keep expensive work off the UI thread. Virtualize long lists, size images appropriately, and preserve keyboard/screen-reader behavior. Store tokens in the platform credential store. Implement a batch before testing it on the affected platform; a JavaScript test is not proof of a successful Android/iOS build. Use the existing React and TypeScript skills for language/component guidance.
