# phobos-skill-discovery

Call find_skills with a specific stack or task. Prefer installed matches and read them via skill_view before use. If missing, search online and use install_skill; downloads are restricted to owner-approved source repositories and immutable revisions. Installation provides reference material, not permission to run code or access credentials. After work, record outcomes and use owner feedback to refine skill selection. Use propose_procedure to retain a reusable draft; only owner evaluation and activation allow its reuse. Recall related experiences with memory_recall.
